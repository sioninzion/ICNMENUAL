## 배포

GitHub Pages로 자동 배포됩니다.

`main` 브랜치에 push하면 GitHub Actions가 자동으로 배포합니다.

- 모바일 최적화 (하단 탭바 네비게이션)
- 좌우 스와이프로 화면 전환
- 식당 카드 클릭 시 상세정보 확장
- 구역/카테고리 필터
- 단체 식사 추천 (순위별)
- 참고사항 및 주의사항
